# Test inventory: unit suites and Playwright specs

Moved out of CLAUDE.md. Reference list of what each suite covers, with the pass that added it. Read it before changing what a suite watches, and add a line here when you add a suite. The gates (`theme-tokens`, `layout-variants`, `section-fields`, `studio-guide-names`) are the ones that fail the build on drift.

- `npm run test:unit` to run the 1378 unit tests (node --test) across 108 `*.test.ts` files in `src/lib/`. (`npm test` is the Playwright suite now, per the family test standard.) Three of them are GATES rather than ordinary suites, and they are the ones to read before changing what they watch: `theme-tokens` (contrast over the `@theme` palette), `layout-variants` (re-derives each grid's base columns from the `.astro` source), and `section-fields` (parses the block schemas and fails when a section gains or loses a `headingAccent` or a rich twin without the in-canvas registry agreeing -- and when a block grows a colour field, per rule 9). The rest cover the pure logic: `sectionCadence`, `sectionVisibility`, `reservedSlugs`, `slugify`, `heading-accent` (the one accent splitter, for both the script and the colour accent), `inline-rich-write`, `sanity-path`, `sanity-dedupe-alias` (the Windows `astro dev` alias repair, card 60), `surfaces`, `redirects`, `page-checks`, `undoRedo`, `utils`, `convert-body` (the Wix-HTML-to-Portable-Text converter, including the dash normaliser rule 2 depends on), the seven `preview-*` modules, and, added in the art-direction pass, `spare-images` (the shared spare-image pool), `hero-frames` (since 2026-09-24 also the full hero's hotspot-to-object-position and its covered-width `sizes`), `live-sunday` / `live-sunday-inline` (the drift gate between the server string and the client upgrade script), and `cta-href` (the one place a `ctaBlock` resolves to an href), and, added in the journal pass, `sermon-derive` (a preview's Sunday, reading and series), `post-body` (the reading pass over post bodies: tables, points, Q and A, the reading, dead anchors) and `post-neighbours` (the Sunday-before and Sunday-after doors).
